# Technique T0165.005: AI-Edited Content

**Summary**: AI has been used to edit existing content.<br><br>Individuals have been observed using AI to modify existing media without disclosing they have done so. Sometimes this is done with the intent to provide higher resolution versions of existing media, however the output cannot be relied upon to accurately represent what was depicted.<br><br>To make the assertion that AI was used to edit existing content, analysts will need to provide evidence that AI has been used in the generation of the content (e.g. via watermarks, or other indicators), and identify the original source material which was edited using AI.

**Tactic**: TA06 Develop Content <br><br>**Parent Technique:** T0165 Edited Content

Analysts who identify imagery nudified using AI should document it using T0166.003: AI-Nudified Imagery instead of T0165.005: AI-Edited Content.
