# Technique T0165: Edited Content

**Summary**: This Technique can be used to assert that a piece of content has been published which was edited in some way without disclosure. <br><br>This technique’s sub-techniques provides analysts options for documenting different ways of editing content, and edits made to content.<br><br><b>Backwards Compatibility</b><br><br>In the 1.7 update to the DISARM Framework, the following Techniques were removed: <br><br>- T0086.003: Deceptively Edit Images (Cheap Fakes)<br>- T0087.002: Deceptively Edit Video (Cheap Fakes)<br>- T0088.002: Deceptively Edit Audio (Cheap Fakes)<br><br>Edits made to content should now be documented using T0165: Edited Content. <br><br>The format of content which was edited can be documented by combining T0165: Edited Content with T0085: Develop Text-Based Content, T0086: Develop Image-Based Content, T0087: Develop Video-Based Content, and T0088: Develop Audio-Based Content.

**Tactic**: TA06 Develop Content
