# Technique T0164.002: Narrative Uses Selective Statistics to Support Claim

**Summary**: A claim is presented alongside supporting statistics which were created using data points which were selectively counted and discounted based on whether they were beneficial to the narrative’s claim (also referred to as “cherry picking”).<br><br>Data can be discounted without counting as cherry picking; sometimes erroneous outliers skew results and need to be removed, some data points may legitimately not be valuable additions to a dataset (for example if they have been influenced by factors outside of the studied area). However, people have been observed using data selectively with the intent of producing evidence to support their claim, rather than building a claim based on unbiased evidence.<br><br>To make this assertion, analysts will need to confirm that data has been selectively chosen to support a given claim, and that it has not been discounted for legitimate reasons.

**Tactic**: TA14 Develop Narratives <br><br>**Parent Technique:** T0164 Issues with Presented Statistical Evidence
